## Featured project · Freedom GPT

**Free, open-source AI on your own computer.** A workspace for local chat, coding projects, files and image generation with compatible models.

| What you get | How it works |
| :--- | :--- |
| **No subscription for local inference** | No Freedom GPT token bill or paid API required. You provide the hardware, electricity and storage. |
| **Your choice of models** | Hardware checks, model discovery, resumable downloads and SHA256 verification. |
| **Projects you can return to** | Saved conversations, files and project notes on your drive. |
| **Local creative tools** | Separate image model packs. Video Studio is experimental. |
| **Open development** | MIT application source, English and Russian interface, public releases and known limitations. |

### Choose your system

<p><a href="https://aionpc.ru/en/install/windows/"><strong>Windows 10 / 11 · x64 ↗</strong></a><br>Installer or portable ZIP. Python and engines included.</p>
<p><a href="https://aionpc.ru/en/install/ubuntu/"><strong>Ubuntu 24.04 · x64 ↗</strong></a><br>Standalone .run, DEB and TAR.GZ packages.</p>
<p><a href="https://aionpc.ru/en/install/macos/"><strong>macOS · Apple Silicon preview ↗</strong></a><br>M1+, macOS 26.2+. Unsigned; native Mac execution is not yet verified.</p>

Downloaded local models can work **offline**. Web tools, new downloads and updates need internet. Model licenses are separate, and speed depends on your hardware. This project does not provide free access to proprietary cloud models.

**Start here:** [Installation guide](https://github.com/Leongrupp/freedom-gpt/blob/main/INSTALL.md) · [Choose a model](https://aionpc.ru/en/guides/choose-model/) · [Actual checks and limitations](https://github.com/Leongrupp/freedom-gpt/blob/main/VERIFICATION.md)

## Building in the open

My current focus is improving Freedom GPT: clearer setup, useful agent workflows, model compatibility, accessible interfaces and reliable local creative tools. Mac validation and broader video support are ongoing work, not finished promises.

**Stack:** Python · JavaScript · local model APIs · GGUF / llama.cpp · CUDA / Metal where supported.
